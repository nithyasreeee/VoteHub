# 🗳️ VoterHub – Voting Poll System

VoterHub is a **frontend-based voting poll system** developed as a class task/project. The project focuses on creating a simple and user-friendly voting interface using **HTML, CSS, and JavaScript**.

Users can view available polls, select their preferred option, and participate in the voting interface.

> **Note:** This is an academic frontend project created for learning and UI development purposes. It is not intended to be used as a real-world election or secure voting system.

## ✨ Features

* 🗳️ Simple voting poll interface
* 📋 Display available poll questions and options
* ✅ Select and submit a vote
* 📊 Display voting results
* 🎨 Clean and responsive user interface
* ⚡ Interactive functionality using JavaScript
* 📱 Basic responsive design for different screen sizes

## 🛠️ Technologies Used

* **HTML5** – Page structure
* **CSS3** – Styling and responsive UI
* **JavaScript** – Voting interaction and dynamic functionality

## 🚀 How to Run

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder.

3. Open `index.html` in your browser.

That's it! No backend or database setup is required.
